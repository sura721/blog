# 📝 Surafel's  Blog

A modern full-stack **blog platform** built with cutting-edge web technologies. It allows you to create, read, and manage articles with a clean UI and dynamic content.

## 🔍 Features

- 🧠 Dynamic blog posts (Markdown or Rich Text)
- ⚡ Fast rendering with Next.js App Router
- 🗂️ Categories, slugs, and SEO-friendly URLs
- 🔐 Admin dashboard for content management
- 🌓 Dark/Light mode support
- 📱 Fully responsive and mobile-friendly

## 🛠️ Tech Stack

- **Frontend**: Next.js, TypeScript, Tailwind CSS
- **Backend**: Node.js, API Routes, Prisma
- **Database**: mongodb (via Prisma ORM)
- 
- **Hosting**: Vercel
